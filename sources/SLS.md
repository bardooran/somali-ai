# Somali Language Standard (SLS)

This project currently uses the Somali Language Standard (SLS) as one linguistic reference for orthography and grammar research.

## Status caution

As of 2026-08-30, SLS states that its current standards are still at `Proposed` status and that no standard is `Stable`. Rules derived from SLS must therefore be marked provisional in this repository until independently reviewed and tested.
