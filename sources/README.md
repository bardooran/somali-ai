# Sources

Human-readable notes about external linguistic resources used by the Somali grammar project.

This folder explains what a source is useful for, what its limitations are, and how project evidence derived from it should be interpreted.

## Current notes

- `SLS.md` — Somali Language Standard reference notes.
- `lexin.md` — Swedish–Somali Lexin reference notes.

## Difference from `data/sources/`

These two locations have different jobs:

- `sources/` = documentation for humans about external resources and source roles.
- `data/sources/` = structured source-derived data or artifacts used by evidence pipelines.

Do not merge them merely because both contain the word `sources`.

## Source policy

No single source automatically becomes universal project authority.

When sources disagree, preserve the conflict and seek broader validation. Native-speaker project review can confirm, qualify, or challenge a source claim, but regional and contextual variation must remain explicit.

Project rules should retain provenance whenever possible.
