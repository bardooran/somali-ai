# Somali corpus

This folder stores collections of **real Somali text** used for research, discovery, stress-testing, and later evaluation.

A corpus is text evidence. It is not automatically a grammar rule.

## Current files

- `maahmaahyo.json` — the project collection of roughly one thousand Somali proverbs (maahmaahyo).

## How to use corpus text

Corpus material can help us:

- discover vocabulary and constructions;
- find real examples that were not used to create a rule;
- stress-test the grammar checker;
- identify false positives and false negatives;
- study idioms, traditional language, and uncommon sentence structures;
- build future evaluation datasets.

## Important caution

Proverbs can contain older language, poetic compression, unusual word order, regional forms, or intentionally fixed expressions. Therefore a proverb should not be promoted directly into an automatic correction rule without separate grammatical review and provenance.
