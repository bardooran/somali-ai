# Stage 1H — controlled Conjugation-2 i+t assibilation generalization

This slice tests whether the finite Conjugation-2 morphophonology layer can extend beyond `kari` without becoming an open-class guesser.

## Independent reviewed evidence

Puglielli & Cabdallah Cumar Mansuur, *Grammatica della lingua somala per le scuole medie superiori* (1997), section 6.3.2.1, describes the causative `-in/-i` extension. On PDF p. 99 it states that when a `t`-initial ending is attached to the relevant `i`-final stem, `t` changes to `s`, and it explicitly prints:

- `wey kari-s-ay (kari+t+ay)`
- `waad joogi-s-ay (joogi+t+ay)`

The source is independent of the frozen v5-v9 benchmark source families and of the Green & Morrison / Saeed evidence used to authorize the first `kari` runtime slice.

## Runtime authorization

Only the explicitly printed `joogi` form is added:

- `joogisay` -> lemma `joogi`, Conjugation 2A, past indicative, 2sg

No 3sg feminine analysis is added even though that person is often syncretic with 2sg, because this source example explicitly identifies only the 2sg context with `waad`.

## Safety

- finite forward generation only
- tense-specific and person-specific authorization
- no reverse stripping of `-say`
- no generic generation for arbitrary i-final stems
- no automatic correction authority
- no v5, v6, v7, v8, or v9 answer is used as runtime evidence
- Fayruus v9 remains evaluation-only
